# emedev

Sitio de EME Dev, la unidad de software e inteligencia artificial de EME: Home y páginas internas (soluciones, industrias, casos, proceso, seguridad, equipo, recursos y diagnóstico).

Vite + React + TypeScript, GSAP/ScrollTrigger, Lenis y Lucide. Tipografía Inter Tight.

```bash
npm install
npm run dev     # http://localhost:5204
npm run build   # salida en dist/
```

- Textos: `src/data/content.ts` y `src/data/pages.ts`
- Sistema de diseño: `src/styles/tokens.css`
- Pendientes antes de publicar: `PENDIENTES.md`
